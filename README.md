# 🏏 IPL Data Analysis using SQL and PySpark

This repository contains exploratory data analysis (EDA) and insights derived from Indian Premier League (IPL) cricket data using **SQL** and **Apache PySpark**. The focus is on understanding team performances, player statistics, match outcomes, and trends across IPL seasons.

## 📌 Objective

To perform data cleaning, transformation, and exploratory analysis on IPL datasets using SQL queries and PySpark DataFrame operations.

## 🛠 Tools & Technologies

- PySpark
- Spark SQL
- Python
- Jupyter Notebook
- CSV Data Files


## 🔍 Key Analysis Performed

### ✅ SQL Analysis:
- Total matches played by each team
- Matches won per team per season
- Top 5 most successful teams
- Teams winning after winning the toss
- Most player of the match awards

### ✅ PySpark Analysis:
- Top batsmen and bowlers (total runs, wickets)
- Strike rate and economy calculations
- Most sixes and fours per player
- Venue-wise match distribution
- Season-wise run distribution

## 📊 Sample Insights

- **Mumbai Indians** is the most successful team in terms of wins.
- **Virat Kohli** has scored the highest number of runs across all seasons.
- **Chinnaswamy Stadium** is one of the most run-friendly venues.
- Batting second has shown slightly higher chances of winning in recent seasons.
